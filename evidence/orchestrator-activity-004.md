## Ownership, maintenance, and security corrections

- Company criticality and maintainer-owned local dependence are separate facts; the
  derived effective class and dominating owner are recorded in every decision trace.
- Git manifest state reaches Company only as a dated maintainer-signed observation.
  Equality/superset/subset/incomparable branch cases use reachability and distinguish
  benign lag, divergent branch, missing history, and stale publication ownership.
- Revocation never rewrites completed Git transactions. It withdraws current support,
  reopens owned decisions, and runs a bounded fail-closed local cascade.
- Divergent fan-out names responsible principal and destination closing authority,
  executes an actual reconcile/abandon workflow, and has a local quarantine terminal
  state if the apology cannot be written.
- Domain-separated Ed25519 signatures bind message type. Verification and semantics
  use one parse of one immutable buffer. Authorization scope uses exact canonical
  equality and bound SQL, never pattern matching.
- All Company reads/writes require capability token plus client-key request signature;
  directory access is separate. Classifier executable is absolute, owner/mode checked,
  digest-pinned, shell/PATH-free, and verified before private bytes.
- Shared projector/writer helpers run under a shipped OS sandbox denying Personal;
  shared use disables if its startup denial probe fails. Shared helpers receive no
  Personal path/config/descriptor.
- Hard-blocking taint is explicitly limited to deterministic configured classes;
  other private meaning remains approval-gated and measured. The public result says
  zero observed unauthorized durable disclosure only outside the named authorized
  processor boundary and only across the digest-bound finite execution census.
- Approval uses inline immutable bytes, domain-separated token, destination atomic or
  recoverable admission, unique nonce, bounded journal/retention, and serialized
  prompt-slot reservation. Hourly and consecutive fatigue behavior is non-bypassable
  and its suppression/delivery metrics are acceptance evidence.
- `.kin` uses lowercase computed sharded digest paths, binary Git attributes, signed
  completeness observations, additive legacy compatibility, explicit sparse/worktree/
  submodule behavior, and bounded cold/revocation/fsck states.
- Reducer determinism is over exact events, reducer version, explicit `as_of`, and
  authority cursor. Source lifecycle coverage is an adapter matrix including rewrite,
  clock skew, out-of-order arrival, and derived-fact support withdrawal.

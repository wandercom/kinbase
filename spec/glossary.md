# Glossary

Status: candidate. Authority: product and architecture specifications.

- **ADR**: architecture decision record with an explicit lifecycle status.
- **Agy**: resident, non-authoring Factory Orchestrator process; it sees the goal and
  activity stream, may block/no-op, and cannot implement, test, or issue the verdict.
- **Apology Unknown**: immutable admission that a previously projected or partially
  published claim lost its warrant; it names the responsible party, closing
  authority, affected decision, and required reconciliation.
- **Advocate**: multi-persona independent review CLI used for advisory design and
  security criticism; it has no product authority.
- **Atom**: one minimal claim, constraint, decision, rationale, observation, or
  Unknown proposed from evidence.
- **AuthorityRegistry**: Company-owned mapping from a question scope to a named
  person, key, and delivery channel.
- **Authority-only**: mechanism-control arm with baseline repository access and
  required use of the frozen fact-only authority service, but no maintained corpus
  or projector.
- **Codebase**: repository-scoped Kindex product whose shared events travel in Git
  under `.kin/`.
- **Company**: organization-wide knowledge authority exposed by Guildhall.
- **Corpus Builder**: schema-blind role that deterministically seals historical
  Company/Codebase snapshots for the whole candidate-revision census before learning
  tasks, ground truth, eligibility, arms, or scores.
- **Current view**: deterministic reducer output over admitted immutable events; a
  disposable cache, never source authority.
- **Canary**: randomized protected marker whose permitted destinations and detectable
  transformations are frozen so an unauthorized recovery becomes mechanical evidence.
- **Constrain**: requirements/constraint interview and synthesis tool used before
  ratification; its generated artifacts are advisory when they conflict with source
  authority.
- **Disposition**: lifecycle state of source evidence, such as proposed, accepted,
  rejected, reverted, expired, retracted, or withdrawn.
- **Distortion cost**: expected loss when a fact is absent as a named dependent
  decision fires.
- **Evidence tier**: progressively more expensive source material fetched by the
  decision loop.
- **Factory method**: distinct Orchestrator, Validator, Coder, and Tester roles with
  exact intent and independent judging; this run uses the current Factory doctrine
  from `../factory` but labels tmux evidence `METHOD_POC`.
- **CLEAN_QUALIFIED**: stronger Factory evidence label requiring the current formal
  harness and isolation contract; this interactive tmux run does not claim it.
- **METHOD_POC**: honest label for applying current Factory role/method discipline
  without claiming formal harness qualification.
- **`../factory`**: required sibling checkout that supplies the current Factory role
  and orchestration doctrine; it is development machinery, not a runtime dependency.
- **`../kindex`**: required sibling checkout/package for the Personal and legacy
  Codebase adapter seams pinned by the proof.
- **fsck**: deterministic integrity/reconciliation check over signed events,
  manifests, repository identity, completeness, and derived caches.
- **F1**: harmonic mean of precision and recall for a classification label.
- **Full system**: experimental arm using maintained corpus, temporal/authority
  reduction, Unknown loop, and set-conditional selection.
- **Null system**: full Guildhall host/hook/tool/policy/timing machinery with an empty
  corpus, empty projection, and typed empty authority response; it falsifies benefit
  attributable only to integration scaffolding.
- **Static prior**: one small task-independent generic conventions document with no
  maintained store, retrieval, temporal logic, or authority loop; it controls the
  cheapest constant-context explanation.
- **Guildhall**: the Company-memory service and client implemented in this repository.
- **Kindex**: the existing local persistent knowledge-graph package in `../kindex`;
  Guildhall integrates it rather than redefining every graph operation.
- **Oracle-spec**: fully informed experimental comparator containing exactly the
  pre-change authoritative load-bearing facts, not an accepted patch or hidden test.
- **Oracle Curator**: schema-blind role that freezes the repository-history census,
  neutral pre-change fact-only comparator, authority replies, and load-bearing labels
  without seeing Guildhall design or candidate outputs.
- **Personal**: principal-private Kindex product, never mounted into coding queries.
- **Logical key**: stable fact subject within one authority scope whose surviving
  immutable event heads are reduced into a current fact or conflict.
- **Simulacrum**: sharp framing-adversary CLI used to expose circular or malformed
  claims; it is neither factual recall nor product authority.
- **Soak**: time/session-bounded private canary operation required before any
  non-private repository remote can receive `.kin/` events.
- **Steward / maintainer / scoped authority**: Company steward owns Company fact
  admission and registry; repository maintainer owns one Codebase identity/reference;
  scoped authority answers one registered question scope. None inherits another's
  authority by role prestige.
- **Taint**: non-clearable private provenance classification; policy may hard-block
  a shared destination or require destination-specific exact-byte approval.
- **Tripwire**: pre-commit scan that blocks staged shared bytes when protected lineage
  or forbidden material is detected.
- **PoC / proof of concept**: a running end-to-end system that meets the outcome and
  safety falsifiers, not an implementation-shaped scaffold.
- **Projection / working set**: the bounded set of admitted facts supplied for one
  decision. This is distinct from a current view.
- **Run Integrity Auditor**: outcome-blind role that seals manifest-derived validity
  from launch/environment telemetry before candidates, scores, or arm identities are
  unblinded.
- **Semantic digest**: Company-published versioned digest of a fact's canonical
  semantic form; Codebase copies rather than recomputes it.
- **Unknown**: first-class unresolved decision dependency with a named owner,
  question, needed evidence, distortion, and deadline policy.
- **Acceptance Threat Model**: exact ratified finite attack/observation contract that
  qualifies the zero-observed-disclosure claim; it is not a universal privacy proof.
- **VOI / value of information**: expected improvement in a decision from obtaining
  evidence, net of acquisition cost; the proof implements an explicit approximation.
